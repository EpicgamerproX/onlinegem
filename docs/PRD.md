# Product Requirements Document

## Overview
OnlineGem is a horror game where the player's microphone input directly influences the game world, creating a unique fear-driven experience.

## Core Mechanics
- Microphone analysis drives entity behavior and fear levels
- Office environment exploration
- Survival horror elements

## Phase 1: Single Player
- Basic game loop
- Mic integration
- Fear system

## Phase 2: Multiplayer
- Networked gameplay
- Voice chat integration
